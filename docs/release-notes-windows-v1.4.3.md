# ACS View 1.4.3 para Windows

A versão inclui o painel de vacinação no resumo individual, o registro em lote de vacinas atrasadas e os ajustes de importação, visitas e controle vetorial. A tela de login e a seleção de contas lembradas também foram atualizadas.

Baixe o ZIP x64, extraia todos os arquivos e execute **ACSView.exe**. Confira a integridade do ZIP com **SHA256SUMS.txt**. [Guia de instalação e atualização](https://github.com/TexDiego/ACS-View/blob/windows-v1.4.3/docs/windows-download.md)
