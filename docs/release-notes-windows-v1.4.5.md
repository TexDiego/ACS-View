# ACS View 1.4.5 para Windows

Esta versão atualiza o catálogo e o calendário de vacinação, o registro de aplicações periódicas e sazonais, os indicadores e as sugestões de visitas. As indicações marcadas para avaliação dependem da conferência da equipe de imunização.

Extraia todos os arquivos do ZIP x64 e execute **ACSView.exe**. Use **SHA256SUMS.txt** para conferir a integridade do download. [Guia de instalação e atualização](https://github.com/TexDiego/ACS-View/blob/windows-v1.4.5/docs/windows-download.md)
