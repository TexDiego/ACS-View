# ACS View 1.4.6 para Windows

Esta versão reúne a importação de pacientes e residências, apresenta as duplicidades internas das planilhas no histórico e acrescenta a métrica de pacientes com residência sem família identificada.

Extraia todos os arquivos do ZIP x64 e execute **ACSView.exe**. Use **SHA256SUMS.txt** para conferir a integridade do download. [Guia de instalação e atualização](https://github.com/TexDiego/ACS-View/blob/windows-v1.4.6/docs/windows-download.md)
