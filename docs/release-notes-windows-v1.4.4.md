# ACS View 1.4.4 para Windows

A tela inicial ganhou atalhos para anotações, notificações, CIDs e métricas. A exclusão individual agora é permanente e remove visitas e registros de saúde vinculados após confirmação.

Extraia todos os arquivos do ZIP x64 e execute **ACSView.exe**. Use **SHA256SUMS.txt** para conferir a integridade do download. [Guia de instalação e atualização](https://github.com/TexDiego/ACS-View/blob/windows-v1.4.4/docs/windows-download.md)
