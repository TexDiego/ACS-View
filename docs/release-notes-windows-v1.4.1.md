# ACS View 1.4.1 para Windows

Esta versão inclui os [recursos compartilhados da v1.4.1](https://github.com/TexDiego/ACS-View/releases/tag/v1.4.1), como backup criptografado por perfil, visita rápida individual e módulos de acompanhamento de saúde.

- Árvore e grafo familiar na interface desktop, com acesso ao resumo individual.
- Menu de contexto para copiar campos do resumo individual.
- Contas lembradas mediante opção do usuário. O Windows Hello requer uma instalação com identidade MSIX. O ZIP portátil oferece login por senha.

Baixe o ZIP x64, extraia todos os arquivos e execute **ACSView.exe**. O arquivo **SHA256SUMS.txt** contém o hash para conferência da integridade. Veja o [guia de instalação e atualização](https://github.com/TexDiego/ACS-View/blob/windows-v1.4.1/docs/windows-download.md).
