# ACS View 1.4.3

- O resumo individual ganhou um painel de vacinação com totais da caderneta. Na tela de vacinas, é possível registrar vacinas atrasadas em lote e revisar as datas antes de salvar.
- As telas de visitas, diabetes, login e resumo individual foram reorganizadas.
- A importação de pacientes atualiza a associação com famílias e responsáveis conforme os dados disponíveis.
- Foram ajustados os filtros de visitas e de controle vetorial.

A atualização Android é opcional. A versão desktop está na [release do Windows](https://github.com/TexDiego/ACS-View/releases/tag/windows-v1.4.3).
