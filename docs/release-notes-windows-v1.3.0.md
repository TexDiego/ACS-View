# ACS View 1.3.0 para Windows

- Telas desktop para cadastros, famílias, residências, métricas e informações da pessoa, com ajustes de tamanho, rolagem, ícones e popups.
- Correção do fechamento do seletor de pai/mãe no Windows.
- Ajustes de notificações, datas e horários; minimizar preserva a sessão e os formulários, e um novo processo exige login.
- Correções compartilhadas de seleção territorial e sincronização de gestação na importação.

## Download Windows x64

Baixe `ACSView-Windows-v1.3.0-win-x64.zip`, extraia todos os arquivos e abra `ACSView.exe`. Inclui .NET e Windows App SDK. Compatível com Windows 10 1809 ou posterior, x64. Consulte [as instruções](https://github.com/TexDiego/ACS-View/blob/master/docs/windows-download.md).

Pacote portátil sem assinatura de editor. Os lembretes exigem que o aplicativo permaneça aberto. O agendamento com o aplicativo fechado depende de instalação com identidade de pacote e não está incluído neste download.

Esta publicação contém somente Windows. O APK Android permanece na v1.2.1; as correções compartilhadas estão no código para uma futura publicação mobile.

Validação: publicação Windows Release x64 e 12 suítes de regressão aprovadas. O fluxo autenticado com dados reais e a entrega de notificações em outro computador não foram validados nesta publicação.
