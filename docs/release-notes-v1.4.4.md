# ACS View 1.4.4

- A tela inicial dá acesso direto a anotações, notificações, CIDs e ações de métricas.
- A interface de criação de métricas combinadas e a tela de perfil foram ajustadas.
- A exclusão individual agora é permanente e remove visitas e registros de saúde vinculados após confirmação. A lista de cadastros é atualizada após a operação.

A atualização Android é opcional. [Versão para Windows](https://github.com/TexDiego/ACS-View/releases/tag/windows-v1.4.4)
